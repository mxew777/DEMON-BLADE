# DEMON-BLADE

A tiny browser-playable 2D pixel-style action RPG prototype.

## Run it
Open this repository in Replit and use the HTML/CSS/JS template (or open `index.html` in a browser). No build step or dependencies are required.

## Controls
- **Touch:** left virtual pad to move, ATTACK button to strike.
- **Keyboard:** WASD or arrow keys to move, Space to attack.
- Attacks automatically target the nearest enemy in range. Chain three quick attacks for a combo.

## Prototype 0.1
- One small dungeon room
- Eight-direction movement
- One chasing enemy
- Auto-target melee attacks and a three-hit combo
- Player/enemy health bars and touch controls

This is an early gameplay test, not the full game.
