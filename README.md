# DEMON BLADE — Godot Prototype

The project is being rebuilt in **Godot 4 using GDScript**. The old browser prototype is kept in the repository's history, but this project now launches from the Godot scene.

## Open the project
1. Install the official Godot 4 Android editor, or open the project in Godot 4 on desktop.
2. Download this repository as a ZIP from GitHub and extract it on your device.
3. In Godot's Project Manager, choose **Import** and select the extracted folder containing `project.godot`.
4. Open the project and press **Run Project**.

## Controls
- Touch: left virtual stick to move; tap the right side to attack.
- Keyboard: WASD / arrow keys to move; Space or Enter to attack.

## Current prototype
- Top-down dungeon arena
- Eight-direction movement
- Enemy pursuit and contact damage
- Nearest-enemy attack with a three-hit combo
- Red spectral slash effects, impact particles, screen shake
- Touch controls and health bars

This is an early playable foundation. Dedicated sprite sheets, frame-by-frame character animations, sound, and more dungeon rooms will be added in later passes.
